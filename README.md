# Salma & Sama Learning

منصة تعليم منزلية خاصة بسلمى (الصف الخامس) وسما (الصف السابع) للفصل الأول، مبنية تدريجيًا على الرزم التعليمية الفلسطينية المعتمدة منذ 2024.

## V1
- اختيار الطالبة من الصفحة الرئيسية.
- مسار مستقل للصف الخامس والصف السابع.
- أول مادة: الرياضيات.
- حفظ تقدم الدروس محليًا على الجهاز.
- لوحة أب أولية.

## التشغيل
```bash
npm install
npm run dev
```

هذا هو المشروع الحالي. بنية المنهاج التجريبية السابقة لم تعد جزءًا من مسار التشغيل الجديد.
