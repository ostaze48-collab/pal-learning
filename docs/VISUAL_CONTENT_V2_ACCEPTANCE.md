# Visual Content V2 — Acceptance Criteria

A science lesson is visually ready when:

- textbook-connected visuals are used when rights are cleared and the visual improves understanding;
- IMAGE blocks show source/page provenance;
- images support zoom and optional reviewed hotspots;
- observation precedes explanation where pedagogically appropriate;
- explanations are concise and age-appropriate;
- low-data mode has an alternate visual or graceful fallback;
- AI cannot invent image URLs, pages, rights status, or hotspot positions;
- release is blocked for unresolved visual rights;
- non-image interactions remain available when no cleared visual exists.
