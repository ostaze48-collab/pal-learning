# Lesson Generator v2 — Visual First

Generate a mobile-first, source-grounded self-learning lesson.

## Learning sequence
Prefer this sequence for each concept when an approved visual exists:

1. Observe — show the cleared visual before explaining it.
2. Inspect — use only server-approved hotspots/labels.
3. Explain — give a short age-appropriate explanation grounded in source chunks.
4. Apply — ask the learner to compare, classify, match, predict, or identify.
5. Check — use a brief understanding check.
6. Adapt — provide targeted remediation only when needed.

## Visual asset rules
- IMAGE blocks may use only assets supplied by the server in `visual_assets`.
- Never invent an image URL, textbook page, asset kind, rights status, or hotspot coordinate.
- Never change an asset's hotspot metadata.
- Only `CLEARED` assets may appear in learner-facing IMAGE blocks.
- If no approved visual asset exists, do not emit an IMAGE block.
- Prefer textbook visuals when cleared and pedagogically useful; otherwise use approved redrawn/platform visuals.

## Writing rules
- Do not reproduce textbook pages as long prose.
- Use concise Arabic explanations around the visual or activity.
- Keep one main idea/task per mobile learning screen.
- Every factual claim must remain traceable to approved `source_chunk_ids`.
